# Changelog

## 0.1.0-dev — 2026-09-09

Initial development preview based on the LLM Foundry implementation plan.

- Added C17 runtime API and lifecycle, pinned llama.cpp adapter, sampling,
  cancellation, UTF-8 streaming, and stop filtering.
- Added native GGUF/Ollama imports, SHA-256 identity, atomic registry writes,
  bounded inspection, and advisory/hard-budget planning.
- Added raw completion, verified SmolLM2 chat, tokenization, capabilities, JSON
  metrics, warm-model benchmarking, and a C17 GTK desktop interface.
- Added C SDK installation, example consumer, macOS development bundle, Linux
  launcher/icon, tests, sanitizer preset, CI, documentation, and benchmark tools.

This preview does not claim broad architecture compatibility, faster inference,
portable GTK binaries, or completed production release gates. See the compatibility
matrix, validation evidence, and roadmap for exact status.
